# CropTechX — Smart Feed & Silage Quality Portfolio

This is a self-contained Vercel-ready prototype.

## Run locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Put `index.html` in a GitHub repository.
2. Import the repository in Vercel.
3. Keep Root Directory as `./`.
4. Deploy.

## Important
The AI result is a demonstration simulation. It is intentionally not presented as a trained clinical/agricultural ML model. A real model/API can be connected later.
